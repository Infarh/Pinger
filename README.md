# Pinger

Консольный инструмент для непрерывного мониторинга сетевой доступности хоста по протоколу ICMP (ping).

Написан на .NET 9 с поддержкой AOT-компиляции — распространяется в виде единого нативного исполняемого файла без зависимостей.

## Возможности

- Непрерывный пинг с настраиваемым интервалом между запросами
- Отображение скользящего среднего времени отклика
- Подсчёт потерянных пакетов и процента потерь
- Вывод тренда (растёт / падает / стабильно) для текущего времени относительно среднего
- Обновление строки вывода на месте — вся статистика в одной строке
- Отображение актуальной статистики в заголовке окна консоли
- Проверка и загрузка обновлений через GitHub Releases

## Установка

Скачайте последнюю версию `Pinger.exe` со страницы [Releases](https://github.com/Infarh/Pinger/releases) и запустите напрямую — установка не требуется.

## Использование

```
pinger [options] [host]
```

По умолчанию (без аргументов) пингует `ya.ru`.

### Параметры

| Параметр | Описание |
|---|---|
| `-? / --help` | Справка |
| `-h / --host <host>` | Целевой хост (имя или IP) |
| `-p / --pause <мс>` | Пауза между запросами (по умолчанию 250 мс) |
| `-t / --timeout <мс>` | Таймаут ожидания ответа (по умолчанию 1000 мс) |
| `-l / --length <байт>` | Размер буфера пакета (по умолчанию 32) |
| `--ttl <ttl>` | Значение TTL (по умолчанию 54) |
| `-c / --count <n>` | Число запросов (-1 — бесконечно) |
| `--avgt / --averaget <n>` | Вес скользящего среднего (по умолчанию 100) |
| `-e / --ignoreerror` | Не прерываться при ошибке пинга |
| `--cls / --clear` | Очистить консоль перед запуском |
| `-v / --version` | Показать версию |
| `--vv` | Показать только номер версии |
| `-u / --update` | Проверить и скачать обновление |

### Примеры

```
pinger 8.8.8.8
pinger -h google.com -p 500 -c 100
pinger --host ya.ru --timeout 2000 --ignoreerror
```

### Формат вывода

```
[  42]host:google.com(142.250.74.46) +t: 12(avg:  11.7)ms ttl:118 lost:0(  0.0%)
```

- `[  42]` — номер запроса
- `+t:12` — текущее время (мс), знак показывает тренд: `+` выше среднего, `-` ниже, `=` равно
- `avg:11.7` — скользящее среднее (мс)
- `ttl:118` — TTL последнего ответа
- `lost:0(0.0%)` — число потерянных пакетов и процент

## Сборка

Требуется .NET 9 SDK.

```
dotnet publish Pinger /p:PublishProfile=./Pinger/Properties/PublishProfiles/FolderProfile.pubxml
```

Бинарный файл будет находиться в `Pinger/bin/Release/publish/win-x64/Pinger.exe`.
